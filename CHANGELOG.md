# Changelog

## PaperRoute 0.1.0 - 2026-10-20

- Introduced the PaperRoute / 选路译读 identity, original icon, teal desktop theme and compact reading workspace.
- Moved concurrency into the main controls; additional document settings now hide their contents when collapsed.
- Added bounded model failover, shared cooldowns, cancellation, independent QPS controls and paragraph caching.
- Replaced the Windows executable launcher and repaired hidden/minimized window activation.
- Removed promotional UI, QQ/community links, support advertisements and gamified reading-area decorations.
- Added source export, private-data exclusions and explicit upstream attribution/licensing status.
- Added an Alibaba Cloud Model Studio preset, in-app guidance and a regional API setup guide.
- Archived obsolete promotional, Mac and Zotero materials and legacy setup scripts.
- Narrowed the sidebar again and added installed Chinese calligraphy fonts for the quote.
- Added a prominent model-save footer and Save / Discard / Continue editing prompts on close and Escape.
- Verified two-PDF batch processing and clarified the file/folder selection entry points.
- Added a trimmed, offline single-executable package with one-time runtime extraction and persistent user data.

This is a derivative preview. The inherited desktop shell has no explicit separate license in the inspected upstream; see LICENSE_SCOPE.md and PUBLISHING.md.
