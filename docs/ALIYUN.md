# 使用阿里云百炼翻译 PDF

PaperRoute 可以直接连接阿里云百炼的 OpenAI 兼容接口。你在本机填写自己的 API Key；请求直接发送给所选服务。

## 1. 准备 API Key

在百炼控制台开通所需模型，并在对应地域创建 API Key。具体步骤见阿里云的[获取与配置 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)。

这里以北京地域为例。其他地域的 Key 应搭配该地域的接口地址，不能交叉使用。

## 2. 在程序里添加模型

打开「管理模型」，点击「添加阿里云」，填写密钥后点击绿色「保存并启用多模型翻译」。这会将主界面切换到「多模型自动切换」。

| 字段 | 北京地域示例 |
| --- | --- |
| 名称 | 阿里云 · qwen-plus |
| API 地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 模型名 | `qwen-plus` |
| API 密钥 | 你在百炼控制台创建的同地域 API Key |
| 关闭思考 | 此示例勾选，发送 `enable_thinking=false` |

阿里云目前推荐使用业务空间专属域名。北京地域的格式为：

```text
https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

将 `{WorkspaceId}` 替换成控制台中的真实业务空间 ID，或直接复制控制台给出的地址。上表的旧北京域名仍兼容，可用于快速配置。地域、域名及协议以[官方 OpenAI 兼容文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)为准。

这里填写的是 OpenAI 兼容地址；用浏览器打开网址不等于接口可用，保存配置也不会自动发起付费测试。

## 3. 添加备用模型

选中已有行后点击「复制选中」，把名称和模型名改为 `qwen-flash`，保留对应服务的地址和密钥。也可以加入其他平台的模型及密钥。

列表顶部作为首选。某个段落请求超时、报错或返回空正文时，程序尝试下一模型；已经完成的段落保留缓存。全部模型都不可用时会停止并说明原因。

同平台的模型可能共享账号配额；切换模型不能保证解决平台整体故障或账号限流。需要跨平台容错时，可以添加另一个平台的候选。

`qwen-plus` 和 `qwen-flash` 示例支持关闭思考。替换模型后，应按该模型的[思考模式说明](https://help.aliyun.com/zh/model-studio/deep-thinking)决定是否勾选，避免向不支持的接口发送参数。

## 4. 从一页开始

先用「预览首页」检查译文和排版，再翻译全文。可按 Ctrl / Shift 多选 PDF，或者添加整个文件夹；文件依次处理，文件内部按线程数并发。

可先采用 8–16 个线程、每秒 2–5 次请求，再根据账号配额调整。这只是起始建议；线程数与每秒请求数是两个独立设置，增加线程不会提高平台允许的请求额度。

## 常见提示

| 提示 | 优先检查 |
| --- | --- |
| 401 / 403 | API Key 是否正确、地域是否匹配、模型是否开通 |
| 404 | 是否使用 OpenAI 兼容地址、业务空间 ID 和模型名是否正确 |
| 429 | 降低「每秒请求数」和线程数，并检查账号请求/Token 配额 |
| 超时 | 检查网络；适当增加单次时限，或添加其他平台备用模型 |
| 改了模型后未生效 | 点击「保存并启用多模型翻译」，再开始一个任务 |

模型可用性、价格与额度以阿里云控制台和官方文档为准。本项目不内置 API Key，也不提供模型服务转售。

本机密钥沿用 Base64 存储，Base64 不是加密。GitHub 源码和 Release 不应包含个人 `config/local_*.json` 文件。
